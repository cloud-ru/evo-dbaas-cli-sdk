# Constraints

Планка качества `cloudru-dbaas`. Последний пересмотр: 2026-10-23.
Читать до первой строки кода. **Не ослаблять, чтобы изменение прошло** — `tools/floorguard` это ловит,
и такой PR не мержится без решения владельца.

**Где гоняется:** все строки ниже — `task check`, его же запускает CI на каждый PR и push в `main`.

## Пол (всегда, проверяет `go run ./tools/floorguard`)

- Нет новых заглушек линтера: `//nolint`, `#nosec`, `//lint:ignore` (нетто по дифу: перенос — не новое).
- Нет новых пропущенных или сфокусированных тестов: `Skip`/`SkipNow`, `PIt`/`XIt`/`PDescribe`, `FIt`/`FDescribe`, `Focus`.
- Нет новых build-тегов: тег выключает файл из сборки и тестов.
- Заголовок «Code generated … DO NOT EDIT.» — только у файлов, которые генератор воспроизводит байт в байт
  (`tools/gencheck.sh`, шаг `task check`); ручная правка внутри `*.gen.go` — тоже красное. Что и куда
  генерировать (`internal/*/cfg.yaml`, `.mockery.yml`, `scripts/generate.sh`) — решение человека: шаблоны
  генераторов пропускают в сгенерированный файл любой код. CR в `.go` — красное.
- Проверок в тестах (`assert.*`, `require.*`, `Expect`, `Eventually`, `t.Error`/`t.Fatal`) по итогу дифа не меньше, чем было.
- Сценарии сетки e2e (`tests/e2e/testdata/golden/`) не удаляются.
- Нет заглушек вместо кода: `panic("not implemented")`, `TODO`, `FIXME` в новом коде.
- Охраняемое меняет человек: этот файл, `.golangci.yaml`, `Taskfile.yml`, `tools/`, CI,
  хуки, `replace` в `go.mod`. В обычном PR разрешены ровно два хода — снять исключение (правило в
  `.golangci.yaml` и строку W… здесь) и сдвинуть число храповика в строгую сторону.
- Секретов в репо нет: ключи только из env или файла вне репо (`auth`, `config`).

## Что страж не видит

Тест, ослабленный изнутри (`if false { t.Fatal() }`, ранний `return`), — ловит ревью.
Удаление пакета тестов целиком страж видит
(«проверок стало меньше», храповик тестов) — мерж после слова человека. Сгенерированный код (заголовок
«Code generated … DO NOT EDIT.», `generated: strict`) линтер не проверяет, поэтому границы `internal/gen`
проверяются отдельно. Храповик считает число тестов, не их имена: тест, выключенный переименованием
(`TestX` → `testX`) и подменённый пустыми `t.Run`, число не уменьшает — пропавшие `func Test…` проверяет ревью.
